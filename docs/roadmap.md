# Development Roadmap

## v1.0 - completed

- Lexer and keyword recognition
- Recursive-descent expression parser
- AST representation
- Integer arithmetic and comparisons
- Local variables
- Assignment
- `if` / `else`
- `while`
- x86-64 code generation
- End-to-end tests
- GitHub Actions CI

## v1.1 - language completeness

- Logical `&&` and `||`
- `for` loops
- `break` and `continue`
- Better source-location diagnostics
- Correct lexical block scopes

## v1.2 - functions

- Multiple function definitions
- Parameters
- Function calls
- Return types
- System V AMD64 argument passing

## v1.3 - memory model

- Pointers
- Address-of and dereference
- Arrays
- Pointer arithmetic

## v1.4 - compiler architecture

- Explicit intermediate representation
- Semantic analysis pass
- Constant folding
- Dead-code elimination
- Cleaner backend abstraction

## v2.0 - broader C subset

- `char`
- structs
- enums
- string literals
- selected preprocessor support
- substantially stronger diagnostics
